# AI Atlas — Interactive High-Level AI Learning Hub

A minimal, interactive, full-screen learning hub mapping all 40 topics from the Comprehensive AI Concept & Direction Index into 10 progressive levels:

- **Progressive Fog-of-War Horizon**: Start at Level 01 while future levels fade into mist until unlocked.
- **Connected Story Spine**: Every lesson links directly from the previous concept to the next—built for complete beginners with everyday hooks and interactive visual labs.
- **Unpredictable Level Gate Trials**: Randomized 5-mechanic test games (`SORT`, `PIPELINE`, `DETECTIVE`, `TUNER`, `DECISION`) guard each new level.
- **Curated Video + Text Hub**: Direct links to beginner-friendly video explainers and visual reading guides on every single topic.
- **Local + Supabase Cloud Sync**: Saves progress locally out of the box and supports live cross-device sync via Supabase (`supabase/schema.sql`).

## Local Development

```bash
npm install
npm run dev
```
